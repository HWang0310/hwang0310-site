# 《湖北电信收入预估》中文密码重置邮件设计

## 目标

将 Supabase 默认英文密码重置邮件替换为可信、简洁的中文业务邮件，并让邮件按钮直接进入网站现有的服务端 `token_hash` 重置流程。不得发送、显示或尝试读取用户当前密码。

## 已确认文案

- 邮件主题：`《湖北电信收入预估》密码重置`
- 标题：`《湖北电信收入预估》密码重置`
- 正文说明用户收到了密码重置申请，引导其点击“设置新密码”。
- 安全提示：链接仅可使用一次并将在系统设定时间后失效；非本人操作可忽略，原密码不会变化。
- 联系方式：`如有疑问，请联系IBOC-王昊 Tel：18062752550`
- 落款：`湖北电信收入预估系统`

## 链路设计

邮件按钮固定使用：

```text
https://hwang0310.dpdns.org/projects/income-forecast/reset-password/?token_hash={{ .TokenHash }}&type=recovery
```

用户点击后先打开公开重置页。页面只保留令牌于内存并立即清理地址栏；用户输入两次新密码后，Cloudflare Function 将 `token_hash` 交给 Supabase `verifyOtp`，校验账户资料，更新密码和首次密码标记，撤销旧会话并建立新的 HttpOnly Cookie 会话。

## 安全与反垃圾邮件约束

- 不使用 `{{ .ConfirmationURL }}`，避免默认 Supabase 验证跳转与现有服务端流程不兼容。
- 不在邮件中出现当前密码、临时密码、手机号、工号、姓名或 Supabase 项目域名。
- 不使用图片、外部字体、跟踪像素、脚本或远程资源；只有一个主要操作链接。
- 主题和正文不使用营销性措辞、感叹号或诱导性表达。
- 密码只允许用户在网站重置页自行设置；数据库继续只保存 Supabase 的密码哈希。

## 页面频控提示

“找回密码”表单在发送按钮下方常驻显示“每次发送后需等待60秒才能再次申请，请留意收件箱及垃圾邮件。”。发送成功后按钮禁用60秒，提示按秒显示剩余等待时间；服务端返回更长的 `retryAfterSeconds` 时，以服务端时间为准。等待结束后恢复静态提示和发送按钮，不改变服务端同姓名60秒/每小时10次的原子限流。

## 生产配置

托管项目通过 Supabase Dashboard 配置主题和 HTML 模板。163 SMTP 授权码只由王昊本人粘贴到 Supabase 官方后台，不进入仓库、聊天、命令行历史或本地环境文件。保存后只向王昊账户发起一次找回密码测试，验证中文主题、中文正文、网站域名、重置页加载和新密码提交。

## 验收

1. 模板契约测试验证中文主题、中文正文、联系方式和唯一 `token_hash` 链接。
2. 模板不得包含默认英文文案、`ConfirmationURL`、外部资源或明文密码措辞。
3. 现有密码 Functions、类型检查、构建和浏览器回归保持通过。
4. 生产邮件由用户实际收到，点击后进入 `hwang0310.dpdns.org` 重置页，并可完成一次密码重置。
